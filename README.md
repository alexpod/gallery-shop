# Banki.shop — интернет-магазин картин эпохи Возрождения

Тестовое задание: вёрстка страницы интернет-магазина по макету Figma с функционалом поиска, покупки и модального окна товара.

## Стек

- **Vue 2.7** (Options API)
- **TypeScript**
- **Pinia** — хранение состояния корзины с сохранением в `localStorage`
- **Swiper 6** + **vue-awesome-swiper** — слайдер изображений в модальном окне
- **Webpack 5** — сборка проекта
- **SCSS** — стили

## Требования

- Node.js **16.x**

## Установка

```bash
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется по адресу [http://localhost:8080](http://localhost:8080).

## Сборка для production

```bash
npm run build
```

Результат сборки будет в папке `dist/`.

## Реализованный функционал

### 1. Поиск
При вводе текста в строку поиска происходит фильтрация карточек по названию картины. Карточки, не соответствующие запросу, скрываются с анимацией.

### 2. Кнопка «Купить»
При нажатии кнопка проходит три состояния:
- **Купить** — начальное состояние с иконкой корзины
- **Обрабатывается** — 2 секунды с анимацией preloader
- **В корзине** — финальное состояние с иконкой галочки

### 3. Сохранение состояния
Состояние «в корзине» сохраняется в `localStorage` через Pinia и восстанавливается после перезагрузки страницы.

### 4. Модальное окно товара
При клике на название или изображение открывается модальное окно с:
- кратким описанием
- ценой
- слайдером из 2–4 изображений (Swiper)

## Респонсив

Вёрстка адаптирована для экранов от **360px**:
- 4 колонки → 2 колонки → 1 колонка
- адаптивные header и footer
